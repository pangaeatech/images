# Support

Use the GitHub issue tracker for questions, suspected bugs, and feature
requests. Search existing issues first, then provide enough information for
someone else to reproduce the problem:

- the image and tag involved;
- the operating system or CI environment;
- relevant Docker or workflow configuration, with secrets removed;
- expected and actual behavior;
- logs or a minimal reproduction when possible.

Support is provided on a best-effort basis by project maintainers. The issue
tracker is not an emergency or security-response channel; report
vulnerabilities privately by following [SECURITY.md](SECURITY.md).
