# Security Policy

## Supported versions

Only the latest released image tags are actively maintained. Consumers should
pin an explicit version and update to a current release when fixes are
published.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature from this repository's
**Security** tab. Include enough detail to reproduce the issue:

- the affected image, tag, or script;
- the impact and likely attack scenario;
- steps to reproduce;
- any suggested remediation.

Do not include active credentials or other secrets. Do not open a public issue
for a vulnerability or publish proof-of-concept details before maintainers have
had a reasonable opportunity to investigate and release a fix.

If private vulnerability reporting is unavailable, contact a repository
maintainer through a private channel. The maintainer can be found in
[CODEOWNERS](.github/CODEOWNERS).

## Response

The maintainers will acknowledge the report, investigate the affected
components, and coordinate a fix and disclosure. Timelines may vary with the
severity and complexity of the issue.
